Tiện ích dịch văn bản & phím tắt toàn hệ thống cho Windows (hướng dẫn v1.0.12)

1. Tổng quan

DirectTrans chạy nền trên khay hệ thống (system tray). Bạn chọn văn bản trong bất kỳ ứng dụng nào, nhấn phím tắt đã cấu hình để dịch sang ngôn ngữ đích.

Ứng dụng hỗ trợ bốn nguồn dịch:

  • Google Free — không cần API key (phù hợp dùng thử hoặc làm dự phòng).
  • Gemini, GroqCloud, Mistral — cần API key; chất lượng dịch thường tốt hơn, tùy model.

Chọn Provider chính trong Cài đặt.

2. Lấy API key

Đăng ký và tạo key tại nhà cung cấp bạn dùng:

  • Google Gemini: aistudio.google.com/app/apikey
  • GroqCloud: console.groq.com/keys
  • Mistral AI: admin.mistral.ai/organization/api-keys

3. Cấu hình API key trong Cài đặt

Khi chạy file .exe, cửa sổ Cài đặt mở tự động. Bạn cũng có thể mở lại bằng double-click biểu tượng khay hệ thống hoặc chuột phải → Cài đặt / Settings. Giao diện all-in-one (không tab): chọn Theme (Midnight Gold / Aurora Glass / Rose Champagne), ngôn ngữ UI, provider, API, phím tắt trên một màn hình. Tiêu đề hiển thị phiên bản, ví dụ DirectTrans Settings v2.0.0.

1 Dán API key

Chọn Provider, dán key vào ô API key. Nếu dùng Google Free làm nguồn chính, không cần key.

2 Load Models

Nhấn ↻ Load Models để tải danh sách model hỗ trợ dịch (Gemini/Groq/Mistral). Thao tác này cũng lưu key nếu bạn vừa dán key mới.

3 Test & Lưu Key

Nhấn Test để kiểm tra kết nối. Thành công: nhãn xanh Pass; thất bại: nhãn đỏ Fail.

Nhấn Lưu Key / Save Key để lưu cấu hình. Test hoặc Load Models thành công cũng có thể lưu key tự động.

4. Phím tắt & hai chế độ dịch

Mặc định thường có hai phím tắt (có thể thêm/xóa trong khung Phím tắt; danh sách dài dùng Xem thêm):

  • Ctrl+Shift+V — ví dụ Popup, dịch sang Tiếng Việt.
  • Ctrl+Shift+E — ví dụ Popup, dịch sang Tiếng Anh.
A Popup (hiện kết quả)

Chọn văn bản → nhấn phím tắt Popup. Cửa sổ hiện bản dịch; bạn có thể Copy hoặc Replace để thay đoạn đã chọn trong ứng dụng đang dùng.

B Replace (thay thế trực tiếp)

Chọn văn bản → nhấn phím tắt Replace. Bản dịch được chèn trực tiếp (mô phỏng Ctrl+V), không hiện popup. Ứng dụng cố giữ định dạng RTF (in đậm, font…) khi nguồn hỗ trợ RTF.

Phím tắt — lưu ý quan trọng: Không nên dùng Space, F1–F12, Enter, Tab… làm phím chính; ưu tiên chữ/số kèm Ctrl/Shift. Dialog thêm/sửa phím tắt có dòng cảnh báo tương ứng. Dùng phím đặc biệt có thể khiến đăng ký hotkey lỗi.

5. Ngôn ngữ giao diện & tùy chọn khác

Góc trên Cài đặt: chọn ngôn ngữ UI — Tiếng Việt, English, 한국어, 中文, 日本語. Nhãn và font giao diện cập nhật theo lựa chọn.

  • Khởi động cùng Windows — ghi vào registry Run (chỉ tài khoản Windows hiện tại).
  • Cập nhật — mở trang phát hành mới trên GitHub.
  • Góp ý / Feedback — mở email với tiêu đề Direct Trans issue_… và đính kèm file log directtrans.log (cùng thư mục với file exe). Cần Outlook hoặc ứng dụng mail mặc định; nếu không có Outlook, hộp thoại mail mở kèm đường dẫn log để bạn đính kèm tay.
  • Tạm dừng — từ menu khay hệ thống để tắt phản hồi phím tắt (không thoát app).

6. Xử lý sự cố nhanh

  • Không lấy được văn bản: đảm bảo đã bôi chọn văn bản trước khi nhấn phím tắt; thử lại sau khi click vào cửa sổ ứng dụng đích.
  • Phím tắt không hoạt động: kiểm tra trùng phím với app khác; đổi combo trong Cài đặt.

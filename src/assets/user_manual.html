Hướng dẫn sử dụng DirectTrans

Tài liệu offline — mở từ nút User manual trong Cài đặt. Ảnh minh họa: di chuột để thấy kính lúp, bấm để xem kích thước gốc (Esc để đóng).

1. Bắt đầu

DirectTrans chạy nền trên khay hệ thống. Luồng làm việc chuẩn:

  1. Bôi chọn văn bản trong ứng dụng bất kỳ (trình duyệt, Word, Teams, …).
  2. Nhấn phím tắt toàn hệ thống đã cấu hình.
  3. Popup — xem bản dịch, Copy hoặc Replace. Replace (hotkey) — thay trực tiếp, không mở popup.
Nguồn dịch Google Free (không key), Gemini, Groq, Mistral. Chọn provider chính trong Settings; nếu lỗi mạng/hạn mức, app tự thử nguồn dự phòng theo thứ tự cố định.
Ngôn ngữ giao diện Tiếng Việt, English, 한국어, 中文, 日本語 — đổi ở header Settings; nhãn và font UI cập nhật ngay.

2. Cài đặt file exe

  • Giải nén hoặc copy DirectTrans_v*.exe vào thư mục cố định; chạy file exe.
  • Lần đầu: cửa sổ Cài đặt mở tự động — cấu hình API (nếu cần) và phím tắt.
  • config.json và directtrans.log nằm cùng thư mục với exe.
  • Mở lại Settings: double-click icon khay hoặc chuột phải → Cài đặt.
  • Chạy exe mới khi bản cũ còn mở: bản cũ được tắt để bản mới tiếp quản (một instance).

Lấy API key

Chỉ cần khi dùng Gemini, Groq hoặc Mistral làm nguồn chính. Google Free không yêu cầu key.

ProviderĐăng ký / tạo key
Google Gemini aistudio.google.com/app/apikey
GroqCloud console.groq.com/keys
Mistral AI admin.mistral.ai → API keys

Trong Settings, nút 🔗 Get API key (theo từng provider) mở trang tương ứng. Sao chép key và dán vào ô API key; không chia sẻ key công khai.

3. Cài đặt trong Settings

Toàn bộ cấu hình trên một màn hình: theme, ngôn ngữ UI, provider, API, phím tắt và tùy chọn hệ thống.

Nguồn dịch & API

  1. Chọn Provider (Google Free / Gemini / Groq / Mistral).
  2. Dán API key (bỏ qua nếu dùng Google Free).
  3. ↻ Load Models — tải danh sách model dịch; thường đồng thời lưu key vừa dán.
  4. Chọn Model trong dropdown (sau khi load thành công).
  5. Test — kiểm tra kết nối: Pass / Fail trên thanh công cụ.
  6. Save Key — lưu key và model vào config.json (mã hóa DPAPI trên Windows).

Icon × trong ô API key xóa nội dung nhanh. Khi chạy từ exe, tên model mặc định có thể reset mỗi lần khởi động; API key được giữ.

Theme & header

Dropdown theme: Midnight Gold, Aurora Glass, Rose Champagne, Nord Snow (light). Các nút User manual, Feedback, Update nằm trên header.

4. Phím tắt

Mặc định thường có hai hotkey (Popup → Việt / Anh). Thêm, sửa, xóa trong khung Phím tắt; nếu có hơn 5 dòng, dùng Xem thêm.

Chế độHành vi
PopupHiện cửa sổ kết quả; Copy hoặc Replace từ popup.
ReplaceThay đoạn đã chọn ngay (giữ RTF khi ứng dụng nguồn hỗ trợ).

Gợi ý phím: Dùng chữ/số kèm Ctrl/Shift/Alt. Tránh Space, Enter, Tab, F1–F12 làm phím chính — dễ trùng hệ thống hoặc đăng ký hotkey thất bại.

5. Popup dịch

Hiện sau phím tắt chế độ Popup, căn giữa màn hình (hỗ trợ DPI scale cao).

Thành phầnChức năng
Dòng trạng tháiHiển thị provider đã dịch (kể cả khi dùng fallback).
Theme (combo)Đổi giao diện popup; đồng bộ với Settings nếu đang mở.
Font color & sizeMàu hex và cỡ chữ kết quả; lưu theo từng theme.
CopySao chép bản dịch vào clipboard.
ReplaceẨn popup, quay lại app nguồn và thay đoạn đã chọn.
EscĐóng popup dịch.

Trong lúc Đang dịch…, Copy/Replace bị vô hiệu đến khi có kết quả hoặc lỗi.

6. Tùy chọn & khay hệ thống

  • Khởi động cùng Windows — ghi registry Run (tài khoản hiện tại); khi nâng cấp exe, đường dẫn autostart được cập nhật tự động.
  • Update — kiểm tra / mở trang phát hành GitHub.
  • Feedback — soạn email kèm log directtrans.log (ưu tiên Outlook).
  • Menu khay: Bật/Tắt tạm dừng phím tắt (không thoát app), Thoát đóng hoàn toàn.

7. Xử lý sự cố

Không lấy được văn bản Bôi chọn trước khi nhấn hotkey; click lại cửa sổ app đích; thử Copy thủ công để kiểm tra clipboard.
Hotkey không phản hồi Kiểm tra app đã bật trên khay; không ở trạng thái Tắt; đổi combo tránh trùng phần mềm khác.
Test API Fail Key sai/hết hạn; chưa Load Models; firewall chặn HTTPS; thử provider khác hoặc Google Free.
Replace sai định dạng Một số app không xuất RTF qua clipboard — chỉ thay plain text; xem ghi chú kỹ thuật trong repo nếu cần.
